# Export Pictures and Audio

**Discovered During:** personal-thoughts-maui-app_2026-10-18

## Context
The MVP exports text only. Embedded pictures and audio clips appear as placeholders.

## Known Scope
Bundle the .txt or a Markdown file with the media/ files into a .zip shared via the share sheet. Markdown can link to the images by relative path.

## Trigger for Promotion
When the user wants attachments to be included in exports.
